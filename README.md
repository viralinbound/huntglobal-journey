# Hunt Global — The Journey (redesign sample)

A redesign concept for [huntglobal.co](https://www.huntglobal.co/): one scroll-driven journey in which a 3D globe travels from section to section and changes its material to match the story. Each company also gets its own chapter, with its logo on the globe.

- Static site: `index.html`, `styles.css`, `journey.css`, `motion.css`, `main.js`, `motion.js`
- three.js 0.160 (jsDelivr), GSAP 3.12 + ScrollTrigger (cdnjs)
- All copy, logos and the hero video come from huntglobal.co
- Forms open an email to hello@huntglobal.co (no backend)

Run locally: `python -m http.server 3072`, then open http://localhost:3072
